# E-commerce Data Engineering Lab

This project takes 500 raw online orders through the 12-step data engineering road-map, from loading the raw CSV to a cleaned, enriched dataset saved as CSV and JSON.
The raw file contains realistic grime: `$` prices, negative prices, blank fields, mixed date formats, inconsistent city and coupon spellings, and duplicate orders.
Each order is modelled as a `Transaction` class with `clean()` and `total()` methods, then enriched with state and population from a public US city dataset.
The notebook ends with revenue per city and an insight about average order value and market reach, followed by a data dictionary merged from both sources.

## Quick start

```bash
python -m venv venv
source venv/bin/activate          # Windows: venv\Scripts\activate
pip install -r requirements.txt
jupyter notebook ecommerce_data_engineering.ipynb
```

Then choose **Run → Run All Cells**. The notebook writes its outputs to `data/processed/`.
It has been tested top-to-bottom with Python 3.11 + pandas 2.2 and Python 3.14 + pandas 3.0.

## Repository layout

```
ecommerce_data_engineering.ipynb   the 12-step notebook (the deliverable)
data/raw/                          input files, never modified
data/processed/                    cleaned CSV + JSON written by Step 11
scripts/generate_transactions.py   rebuilds data/raw/transactions.csv
requirements.txt
```

## Data sources

- **Primary: `data/raw/transactions.csv`** (500 rows). Synthetic, generated by [`scripts/generate_transactions.py`](scripts/generate_transactions.py) with a fixed seed (`8245`). To regenerate it, run `python scripts/generate_transactions.py`. I used synthetic data because the suggested [ExcelBIAnalytics sample files](https://excelbianalytics.com/wp/downloads-18-sample-csv-files-data-sets-for-testing-sales/) have no `customer_id`, `coupon_code` or `shipping_city` fields.
- **Secondary: `data/raw/us_cities_top_1k.csv`** (1,000 rows). [US cities top 1k](https://github.com/plotly/datasets/blob/master/us-cities-top-1k.csv) from Plotly's open `datasets` repository: city, state, population, latitude and longitude.
